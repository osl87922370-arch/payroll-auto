계산 기준 안내

1. 기본급 계산

월급제기본급 직접 입력 (209시간 기준, 주휴수당 포함)
시급제시급 x 주 소정근로시간 x 4.345주 (근로분만, 주휴수당 별도)
209시간 = (주 40시간 + 주휴 8시간) x 4.345주

2. 주휴수당

대상주 15시간 이상 근무, 소정근로일 개근
월급제0원 (기본급 209시간에 이미 포함)
시급제시급 x 주휴시간 x 4.345주
주휴시간(주 소정근로시간 / 40) x 8시간

3. 법정 가산수당 (5인 이상 사업장)

연장근로수당통상시급 x 1.5 x 연장시간 (주 40시간 초과)
휴일근로수당통상시급 x 1.5 x 휴일근로시간
야간근로수당통상시급 x 0.5 x 야간시간 (22시~06시)
5인 미만 사업장: 가산수당 법적 의무 없음 (주휴수당만 의무)

7. 실수령액 공식

실수령액 = 총 지급액 - 4대 보험(근로자) - 소득세 - 주민세
총 지급액 = 과세 소득(기본급 + 과세 수당) + 비과세 소득
