1. 급여 계산기 사용법

월급제 직원

  1. 월급 직접 입력 모드를 선택합니다.
  2. 기본급을 입력합니다. (예: 3,500,000원)
  3. 부양가족 수를 입력합니다. (본인 포함, 기본 1명)
  4. 해당되는 수당이 있으면 입력합니다. (직책수당, 식대 등)
  5. 계산하기 버튼을 클릭합니다.
월급제는 기본급에 주휴수당이 이미 포함되어 있어 주휴수당이 0원으로 표시됩니다.

시급제 직원

  1. 시급 x 근무시간 모드를 선택합니다.
  2. 시급을 입력합니다. (예: 10,320원)
  3. 일 근무시간과 주 근무일수를 입력합니다.
  4. 기본급과 주휴수당이 자동 계산됩니다.
  5. 계산하기 버튼을 클릭합니다.
시급제는 주 15시간 이상 근무 시 주휴수당이 자동으로 계산됩니다.

사업장 규모 설정

5인 이상 사업장을 선택하면 연장/휴일/야간 근로에 법정 가산수당(1.5배, 0.5배)이 적용됩니다. 5인 미만은 가산수당 의무가 없습니다.

2. 직원 관리 사용법

직원 추가

  1. 직원 관리 페이지에서 + 직원 추가 버튼을 클릭합니다.
  2. 새 직원 카드가 생성되면 설정 버튼을 클릭합니다.
  3. 성명, 직책, 부양가족 수를 입력합니다.
  4. 급여 모드(월급/시급)를 선택하고 금액을 입력합니다.
  5. 수당 항목을 입력합니다. (해당 시)
  6. 저장 버튼을 클릭합니다.

전체 급여 계산

  1. 직원들의 급여를 모두 설정한 후, 전체 급여 계산 버튼을 클릭합니다.
  2. 모든 직원의 급여가 한 번에 계산되어 요약 테이블로 표시됩니다.
  3. 총 지급액, 사업주 부담, 공제액, 실수령액을 한눈에 확인할 수 있습니다.

급여 명세서 출력

  1. 직원 카드에서 명세서 버튼을 클릭합니다.
  2. 급여 명세서가 표시되면 인쇄하기 버튼을 클릭합니다.
  3. A4 용지에 최적화된 명세서가 인쇄됩니다.
명세서에는 지급 내역, 공제 내역, 사업주 부담 내역, 실수령액이 모두 포함됩니다.

3. 설정 관리

매년 변경되는 요율을 업데이트해야 정확한 계산이 가능합니다.

항목변경 시기
최저임금매년 1월
건강보험 요율매년 1월
장기요양보험 요율매년 1월
국민연금 요율비정기 (현재 9% 유지)
고용보험 요율비정기
산재보험 요율매년 1월 (업종별)
요율이 변경되었는데 설정을 업데이트하지 않으면 계산 결과가 부정확할 수 있습니다.
설정 페이지 하단의 계산 기준 안내에서 각 항목의 계산 방식을 상세히 확인할 수 있습니다.

자주 묻는 질문

Q. 데이터는 어디에 저장되나요?

서버에 JSON 파일로 저장됩니다. 별도의 데이터베이스는 사용하지 않습니다.

Q. 여러 사업장에서 동시에 사용할 수 있나요?

현재 버전은 단일 사업장용입니다. 모든 접속자가 같은 직원 데이터를 공유합니다.

Q. 계산 결과는 정확한가요?

간이세액표 기준으로 추정치를 계산합니다. 정확한 세액은 연말정산 시 확정됩니다.

Q. 비용이 발생하나요?

완전 무료입니다. 어떤 비용도 발생하지 않습니다.

Q. 접속이 느릴 때가 있어요.

무료 서버를 사용하고 있어 15분 이상 미사용 시 서버가 잠듭니다. 재접속 시 30~60초 정도 대기하면 정상 작동합니다.
